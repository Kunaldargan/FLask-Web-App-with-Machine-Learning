About the project

A clearer home for a small machine-learning experiment.

Inflation Lab is a Flask interface around a collection of regression models trained on economic indicators. It started as a classroom project and now has a simpler application boundary, safer input handling, and documentation that matches the code.

What changed

The web layer now has a conventional app.py entry point, an application package, a shared template, named routes, and a dedicated model service. Legacy serialized estimators are loaded lazily so the server can start without doing unnecessary work.

What to remember

The artifacts were trained with an older scikit-learn release. The compatibility loader rebuilds the saved KNN index when possible, but the result is still a historical demonstration, not a production forecasting system.
