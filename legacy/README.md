# Legacy material

These files are retained for provenance from the original classroom project. They are not imported by the current Flask application.

- `training/` contains the original model-training scripts. They use a local Windows dataset path and APIs removed from modern scikit-learn versions.
- `templates/` contains the unused Bootstrap-era pages that were replaced by the shared templates in the project root.
- `frontend/` contains the old Bootstrap, jQuery, font, and test assets.

Keep new web code in `inflation_app/`, `templates/`, and `static/` instead of extending this directory.
